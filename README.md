# Datum Tech Academic Performance Analysis

**Tools:** SQL (PostgreSQL)
**Completed:** January 2025

## Project Overview
Three-part SQL case study analysing student performance, course distribution, and teacher data for a tech education platform, using PostgreSQL across progressively advanced query techniques.

## What I Did
- Wrote INNER, LEFT, RIGHT, and FULL OUTER JOIN queries to connect course, student, score, teacher, and department tables
- Applied CASE/WHEN logic to categorise students as Distinction, Pass, or Fail and teachers as Senior, Mid, or Junior based on salary bands
- Used COALESCE to handle NULL values in course-teacher assignments
- Wrote subqueries to identify students scoring above average and teachers earning below average salary
- Delivered a full SQL query portfolio across SELECT, GROUP BY, HAVING, ORDER BY, CAST, and DISTINCT operations

## Key Skills Demonstrated
- PostgreSQL: INNER/LEFT/RIGHT/FULL OUTER JOINs
- CASE/WHEN conditional logic
- COALESCE for NULL handling
- Subqueries and aggregate functions
- Academic data analysis
