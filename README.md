# Datum Tech Academic Performance Analysis

**Tools:** SQL (PostgreSQL)
**Completed:** January 2025

## Project Overview
Three-part SQL case study analysing student performance, course distribution, and teacher data for a tech education platform using PostgreSQL across progressively advanced query techniques.

## What I Did
- Wrote INNER, LEFT, RIGHT, and FULL OUTER JOIN queries across course, student, score, teacher, and department tables
- Applied CASE/WHEN logic to categorise students as Distinction, Pass, or Fail and teachers by salary band
- Used COALESCE to handle NULL values and wrote subqueries to identify above-average students and below-average salary teachers
- Delivered a full SQL query portfolio covering SELECT, GROUP BY, HAVING, ORDER BY, CAST, and DISTINCT

## SQL Files
- `sql/01_joins_analysis.sql` — INNER, LEFT, RIGHT, FULL OUTER JOINs
- `sql/02_case_coalesce_cast.sql` — CASE/WHEN, COALESCE, CAST
- `sql/03_subqueries.sql` — Subqueries, above-average analysis, department overview

## Key Skills Demonstrated
- PostgreSQL: all JOIN types, CASE/WHEN, COALESCE, CAST, subqueries
- Academic performance and course distribution analysis
- NULL handling and data type conversion
